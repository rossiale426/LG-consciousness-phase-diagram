# LG Consciousness Phase Diagram

Code accompanying: **A Landau-Ginzburg framework for consciousness: 
integration and relational dimensionality define a two-parameter phase diagram**

Journal of Neuroscience, 2025

## Description
Analysis code for computing integration (Φ), relational dimensionality (D), 
susceptibility (χ_D), and temporal variability across conscious and 
non-conscious states (anesthesia, disorders of consciousness).

## Requirements
Python 3.9+
numpy, scipy, matplotlib, nilearn
(see requirements.txt)

## Usage
1. Run analysis/compute_D.py — relational dimensionality
2. Run analysis/compute_phi.py — integration proxy
3. Run figures/plot_figures.py — reproduce main figures

## Data
fMRI data available upon reasonable request to the corresponding author.
